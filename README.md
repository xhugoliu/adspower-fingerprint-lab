# AdsPower 指纹检测实验

用可控的本机页面测试 AdsPower。目标是找出在指定配置下仍可读取的指纹信号，以及浏览器在不同 API、执行环境和读取方式之间暴露的不一致。

[首轮实验记录 · 2026-11-20](experiments/2026-11-20.md)

## 阶段发现

| 项目 | 当前观测 |
| --- | --- |
| 分辨率 | 自定义 `1440 × 900` 时，`screen` 报 `720 × 450`，CSS 设备尺寸查询报 `1440 × 900`。改变窗口尺寸后，两种读数各自保持原值。 |
| WebGL | 图像噪声改变了着色器绘图的 `readPixels()` 结果。同一图像的 PNG 导出和扩展列表保持一致。 |
| 定位 | 选择「阻止」后，定位请求被拒绝，Permissions API 仍报 `prompt`。 |
| 单项变化与访客 ID | 只改时区就改变了 FingerprintJS 演示页的访客 ID。42 个采集字段中有 41 个保持原值。 |

每条发现都对应记录中的浏览器版本、配置和测试方法。后续优先复测分辨率和图像读取方式，再验证这些结果在不同内核和配置下是否重复出现。

## 追加实验

在 `experiments/` 下按日期新增记录。同一天有多轮时，可以在文件名中加序号。每轮用下面几项说明结果。

- **假设** — 网页通过什么方式可以观察到差异。
- **环境** — AdsPower 和内核版本、操作系统、对照浏览器、测试配置。
- **步骤** — 基线、单次改动、采样次数、读取 API 与执行环境。
- **结果** — 记录实际读数、可重复次数、异常和反例。
- **范围** — 注明待复测条件，记录配置是否已恢复。
